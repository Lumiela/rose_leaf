# v6_holefilter: 추론 파이프라인 (v4 모델 + 화이트밸런스 + Hole 후처리 필터)

재학습 없이 추론 단계만 바꾼 버전입니다(2026-10-13). 모델 가중치는 v4(`v4_reallabel/runs/ft_from_v2ft/weights/best.pt`)를 그대로 씁니다.

```
v6_holefilter/
├── scripts/
│   ├── pipeline.py   # Pipeline 클래스: 화이트밸런스(gray-world) → v4 예측 → Hole 필터
│   └── eval_v6.py    # 실제 사진 3종(큐브 18장, 고정 카메라 1장, 기존 3장) 평가
├── eval/             # summary.csv, <사진>_v6.jpg(제거된 Hole은 회색 윤곽), hole_review_*.jpg(Hole 판정별 KEEP/DROP)
└── logs/
```
실행: `python v6_holefilter/scripts/eval_v6.py` (model/에서)
사용: `from pipeline import Pipeline; pl = Pipeline(); res, img = pl.predict(rgb)` (기본값: wb=True, hole_min_leaf=0.5, conf=0.25)

## Hole 필터 규칙
Hole 판정 영역 안에서 잎 색(HSV H 20~95, S≥40, V≥40) 픽셀이 차지하는 비율이 `hole_min_leaf`(기본 0.5) 미만이면 그 판정을 버립니다.

## 결과 (Hole 판정 수)
| 사진 세트 | v4 원본 | +화이트밸런스 | +필터 0.3 | **+필터 0.5** | +필터 0.7 |
|---|---|---|---|---|---|
| 큐브 18장 | 211 | 181 | 142 | **129** | 105 |
| 고정 카메라 1장 | 14 | 14 | 10 | **10** | 6 |
| 기존 실사 3장 | 56 | 57 | 52 | **50** | 42 |

- **큐브 18장 합계:** 원본 대비 Hole -39%, Yellow -79%, Black -53% (화이트밸런스 효과 포함)
- **필터가 버린 판정:** 빈 화분 칸, 트레이 구멍, 전선 주변, 흰 벽 쪽 판정으로, 의도한 대로 제거됐습니다.
  - 잎 비율 0.43~0.49로 경계에 걸려 버려진 잎 판정이 일부 있습니다. 분홍 배경 앞의 잎이라 화이트밸런스를 적용한 뒤에도 채도가 낮게 나온 경우입니다.
- **남은 Hole 판정:** 대부분 건강한 잎 무리 판정입니다. 잎 여러 장이 합쳐진 마스크에 잎 사이 틈이 보이는 경우로, 영역 대부분이 잎 색이라 필터로는 제거할 수 없습니다.
  - 고정 카메라 화면에서는 빈 화분 안쪽에 잎이 비쳐 보여, 잎 비율이 높게 나온 큰 Hole 마스크 2개가 남았습니다.
- **결론:** 필터만으로는 빈 칸·물체 오탐 중심으로 일부만 해결됩니다. 남은 오탐(건강한 잎 무리 → Hole)은 아래 방법으로 줄여야 합니다.
  - 고정 카메라 영역 제외(B안): 빈 칸 반사 오탐
  - 큐브 사진 재학습(A안): 잎 무리 오탐
