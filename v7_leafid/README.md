# v7_leafid: 2단계 구조 1단계, 잎 탐색 + ID 부여

**새 아키텍처 (2026-10-14):**
- [1단계] 사진 속 잎을 모두 찾아 ID를 붙입니다. → [2단계] 잎 ID별로 분류 모델로 상태를 판정합니다(예정).
- 기존 v4 모델과 v6 필터(색 보정, Hole 필터)는 그대로 씁니다.

```
v7_leafid/
├── scripts/leaf_search.py     # 1단계: 잎 탐색 + ID 부여 + 잎별 데이터 내보내기
├── runs/<입력>_<시각>/        # 실행 결과
└── logs/
```

## 실행 (model/에서)
```
python v7_leafid/scripts/leaf_search.py <사진 파일 또는 폴더> [--out 폴더] [--conf 0.25] [--min-area 400] [--min-leaf-color 0.3] [--dedup-iou 0.5]
```

## 처리 방식
1. v6 파이프라인(색 보정 → v4 → Hole 필터)을 실행합니다. 이때 **클래스 구분 없이 중복을 제거**(agnostic NMS)해서, 같은 잎이 클래스만 달리해 두 번 잡히지 않게 합니다.
2. 잎이 아닌 것을 제거합니다. 클래스와 상관없이 영역 안의 잎 색 픽셀 비율이 0.3 미만이면 버립니다(트레이, 그림자, 화분 테두리). 갈색으로 마른 잎도 함께 빠지는데, 대상 클래스가 아니라서 문제없습니다.
3. 마스크가 50% 넘게 겹치면 같은 잎으로 보고 하나만 남깁니다. 넓이 400픽셀 미만은 버립니다.
4. 위에서 아래, 왼쪽에서 오른쪽 순서로 ID를 붙입니다(`<사진>_L0001`).

## 출력 (runs/<입력>_<시각>/)
| 파일 | 내용 |
|---|---|
| `<사진>_ids.jpg` | 잎마다 다른 색 윤곽과 ID 번호 |
| `<사진>_cutouts.jpg` | 잎 누끼 전체 모음 (검토용) |
| `crops/<사진>/<ID>.png` | **2단계 분류 모델 입력.** 배경이 투명한 누끼로, common/Dataset과 같은 형식 |
| `context/<사진>/<ID>.jpg` | 주변을 포함해 잘라낸 이미지 + 윤곽 |
| `leaves.csv`, `leaves.json` | 잎마다 ID, 박스, 중심점, 넓이, v4 참고 클래스·신뢰도, 잎 색 비율, 선명도, 화면 가장자리 접촉 여부, 볼록도(solidity, 낮으면 여러 잎이 합쳐졌을 가능성) |

## 배경 물체 필터 추가 (2026-10-14, runs/real_images_camfix_20261014_005116)
**배경 물체 오판:** 빈 화분, 물에 비친 반사, 잎 사이로 보이는 회색 트레이를 잎으로 잡는 경우가 확인됐습니다. 그래서 중복 제거 뒤에 잎 영역의 색 통계로 배경을 걸러내는 필터를 추가했습니다(색 보정된 이미지 기준).

**사용하는 색 통계:**
- `exg`: 녹색 지수 (2G−R−B)/(R+G+B)의 중앙값
- `sat`: 채도 중앙값
- `dark`: 어두운 픽셀 비율

**버리는 조건 (하나라도 해당하면):**
- `exg < 0.12`: 초록이 거의 없음
- `dark > 0.25` 그리고 `exg < 0.25`: 빈 화분, 물, 화분 테두리
- `sat < 0.26` 그리고 `exg < 0.15`: 잎 사이로 보이는 회색 트레이

**기준값 설정 근거:** 642개 검출 중 의심 39개를 눈으로 분류하고, 같은 조건을 전체에 적용해 확인했습니다.
- 배경 26개 중 25개 제거
- 잎과 비슷한 의심 6개는 하나도 제거되지 않음
- 실제 실행에서 39개가 제거됐고, 제거 목록(`<사진>_bg_dropped.jpg`)을 눈으로 확인한 결과 모두 화분·트레이·틈이었습니다.

| 사진 | 이전 | 배경 제거 | 이후 |
|---|---|---|---|
| camfix_01~03 | 110 / 93 / 100 | 9 / 6 / 8 | 101 / 87 / 92 |
| camfix_04 | 195 | 8 | 187 |
| camfix_05 | 144 | 8 | 136 |

- **끄는 방법:** `--no-bg-filter` 옵션으로 끌 수 있습니다.
- **추가 출력:** `leaves.csv`에 `exg`, `sat`, `dark` 열이 추가됐습니다.
- **보조 도구:**
  - `scripts/review_suspects.py <run>`: 의심 검출 모음 이미지
  - `scripts/color_features.py <run>`: 기준값을 정할 때 쓴 분석
- **남은 문제:** 카메라에 가까워 흐린 잎 무리가 덩어리 하나로 잡힙니다(camfix_05 #31). 잎이라 필터로는 걸러지지 않습니다. 볼록도·넓이 기준으로 2단계에서 제외하거나, 재학습으로 줄여야 합니다.
