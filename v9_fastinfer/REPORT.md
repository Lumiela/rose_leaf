## 아키텍처
처리 흐름은 v8과 같습니다. 바뀐 곳은 두 곳입니다.

```
1단계 타일 → GPU에서 마스크 이진화 + 픽셀 수·bbox 계산 → 잎 박스 부분만 CPU로 복사
2단계 전처리 → 기준 픽셀을 GPU 정수 비교로 계산 → 채널별 LUT로 화이트밸런스 적용
```

## 원인 분석 (v8, 12MP)
| 항목 | L=102 사진 | L=165 사진 |
|---|---:|---:|
| YOLO 호출 | 0.88s | 0.49s |
| 마스크 CPU 복사 + 이진화 | 0.83s | 3.26s |
| 마스크별 `np.nonzero` + 자르기 | 1.64s | 5.04s |
| gray world 화이트밸런스 | 2.10s | 1.91s |

측정 중 GPU 사용률은 평균 9%였습니다. 같은 사진에 L을 강제로 바꾸면 1단계가 4.2초(L=100)에서 9.2초(L=165)로 늘어, 잎 크기가 원인임을 확인했습니다.
